Pesos del costo

Ajusta cuánto penaliza A* la pendiente y el índice de radiación MODELADO (0 a 100). El costo total es un ÍNDICE DEL PROYECTO: una puntuación de planificación, no una probabilidad ni una garantía.

costo_paso = longitud × (1 + w_pendiente·pendiente + 2·riesgo + w_radiación·radiación_modelada)

Mapa y capas

Calculado en la interfaz como 1 − radiation_modeled: más intenso = más cielo tapado por el relieve. Es un índice relativo MODELADO, no una dosis ni una medición por celda.

Las etiquetas indican la procedencia que declara la API para cada capa (MEDIDO, DERIVADO, MODELADO, ÍNDICE DEL PROYECTO). Pasa el cursor o enfoca una etiqueta para ver su fuente.

Se priorizan los accidentes grandes y las etiquetas evitan solaparse. Los nombres describen accidentes del terreno, no peligros. MOLA ofrece un proxy topográfico basado solo en pendiente, no una capa de peligros validada.
